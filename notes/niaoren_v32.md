# niaoren 蒸馏笔记 v32
（崔先生符咒战/井水涂镜/救魔法门/兄弟对决：第257-268章，1100000-1159999）

## 世界观构建技法
1. 崔先生隐藏实力揭底：仙骨只是两门本事之一（马家仙骨+三清符咒）；「丁丑子任毁神符」（六丁六甲阴神符/对妖邪爆裂/对人无效）+剑指咒+符咒可制武器——三清书传人（符咒书），师承：韩友→师父→张文财/林叔→崔先生。
2. 井水涂镜（召鬼术）：满月十五丑时（15的月亮16圆）/井水河水+镜子+艾蒿锁气+易欣星奇门改波长（十四也能用）——「跟阴间视频聊天」。
3. 救魔三条件：①非自愿入魔②三清书（符咒）③必死的觉悟——祖师韩友曾以「三魂入心符」入魔者心中，唤醒心中最宝贵的东西（强龙不压地头蛇，险些死）。
4. 三魂入心符：三魂（胎光/爽灵/幽精）脱体入他人思想——贴自己额头再顶对方额头念急急如律令。
5. 魔的本质：「心生善念入佛道，心存恶念堕魔途」；魔=业障非绝对（非自甘堕落可救）——与鬼同理（鬼也能超度）。

## 文风技法
1. 圈内决斗的规则陷阱：直径两米/不用妖气/出圈输——反派用规则克制主角，主角用「符咒不算妖气」破局（「这种狭小的赛场正适合我，我的猎物避无可避」）。
2. 嚣张vs市侩的骂战：崔先生「你算哪颗大鼻子葱」/「咱别要饭还嫌馊」——以牙还牙的语言武器。
3. 文叔的毒舌反差：前店主「够花个六」「我斗地主哪儿输过」——高人形象先崩塌再立起（「不是不让你叫我出来么」）。
4. 师徒情的细节：「眼睛好像是进沙子了」/十座金山换师父/「我没人欺负无聊死了」——毒舌下的深情。
5. 兄弟回忆杀：大学打架（毛毛虫掉头/酒劲/「你他吗松手」）——以最市井的日常铺最重的情谊。

## 结构技法
1. 三场决斗的难度递增：赛跑（克制体力）→圈内肉搏（封仙骨）→兄弟死斗（诛心）——每场都在升级精神折磨。
2. 文叔线插入：以「请救兵」章节破题——崔先生「我不知道怎么办，但不知道不代表没办法」→井水涂镜→韩友旧事→三魂入心符——希望从绝境再生。
3. 燃西的算盘：利用小七记忆洞悉人性弱点（情字致命）——「燃西对人性解剖比子孙更甚」；张是非不敢全力/李兰英魔化更强=稳赢棋局。
4. 崔先生留后手：卵妖结晶只带部分（「留了俩高级的在哈尔滨」）——谈判筹码的攻防。
5. 第三场开打：张是非化孔雀引开/李兰英追袭扔石头（附妖气）——「即使他再入魔不还是李兰英么？把他揍趴下再救」——兄弟对决的破局心态。

## 人物与主题技法
1. 崔先生的柔软：文叔面前秒变三胖哒/「福泽堂有我，有我们，不保证一日千里，但保证风生水起」——对师门的承诺。
2. 文叔的守候：师恩未报不入轮回/等林叔/「咱们四人对着镜子畅饮」——生死师徒羁绊（跨书：yingyang 文叔=希望小学荣誉校长，坑的钱全捐）。
3. 张是非的必死觉悟：「与其坐以待毙被兄弟杀死却救不了他，倒不如放手一搏」；不能对胖子动刀（用拳头）——情义高于胜负。
4. 燃西的诗性：「苍松几经风吹雪，一年明月一年轮」——反派亦有文学性。
5. 主题落点：情是弱点也是力量；救人的关键在于唤醒其「心中最宝贵的东西」；朋友永远在你身后。
